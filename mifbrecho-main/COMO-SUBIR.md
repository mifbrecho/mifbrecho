# 🎀 Como colocar o MIF BRECHO no ar (passo a passo bem simples)

Você **não precisa saber programar**. Só seguir os passos.

No final você vai ter um link tipo:
`https://mifre-brecho.vercel.app`

Esse link você manda no grupo de WhatsApp das clientes.

---

## O que você vai precisar (tudo grátis)

1. Uma conta no **GitHub** (grátis)
2. Uma conta no **Vercel** (grátis)
3. (Depois) conta no **Supabase** e **Mercado Pago** — só quando for usar de verdade

Por enquanto o app já funciona com dados de exemplo (peças fictícias).

---

## Passo 1 — Criar conta no GitHub

1. Abra o site: https://github.com
2. Clique em **Sign up**
3. Crie sua conta (pode usar e-mail do Gmail)

---

## Passo 2 — Subir o código pro GitHub

Eu te entreguei a pasta `mifre-brecho`.

**Opção mais fácil (recomendada):**

1. Entre no GitHub logado
2. Clique no botão verde **New** (novo repositório)
3. Nome: `mifre-brecho`
4. Deixe público
5. Clique em **Create repository**
6. Depois me avise que eu te ajudo a enviar os arquivos (ou use o botão de upload de arquivos do GitHub)

---

## Passo 3 — Colocar no ar com Vercel (grátis)

1. Abra: https://vercel.com
2. Clique em **Sign up**
3. Escolha **Continue with GitHub** (entre com a conta que criou)
4. Clique em **Add New Project**
5. Selecione o repositório `mifre-brecho`
6. Em **Root Directory** escolha: `apps/web`
7. Clique em **Deploy**

Espere 1–2 minutos.  
Quando terminar, a Vercel te dá um link.

**Esse é o link das clientes!**  
Exemplo: `https://mifre-brecho.vercel.app`

Link do admin: `https://mifre-brecho.vercel.app/admin`

---

## Passo 4 — Testar

1. Abra o link no celular
2. Veja as peças
3. Adicione no carrinho
4. Vá até o final (Pix de exemplo)
5. Abra o link `/admin` e veja o painel

---

## Depois (quando quiser usar de verdade)

Aí a gente configura:

- Supabase → para salvar as peças de verdade e estoque automático
- Mercado Pago → para gerar Pix real

Eu te ensino isso também, no mesmo estilo simples.

---

## Resumo rápido

| O quê | Link |
|-------|------|
| Clientes (grupo WhatsApp) | `https://seu-link.vercel.app` |
| Admin (sua irmã) | `https://seu-link.vercel.app/admin` |

Você sobe **uma vez**. Depois o site fica no ar sozinho, 24 horas, grátis, com o computador desligado.

Qualquer dúvida é só perguntar que eu te guio no próximo passo.
